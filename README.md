# PlanPilot

PlanPilot is a modern product planning app that helps teams turn a rough idea into a clear, structured delivery plan.

## Features

- Project brief form for name, objective, audience, timeline, constraints, and team
- Automated plan generation across discovery, design, build, and launch phases
- Task-level breakdown with owners, duration, and priority
- Save plan to local storage
- Export plan as JSON
- Example data loader

## Getting started

```bash
npm install
npm run dev
```

Then open http://localhost:3000.

## Stack

- Next.js
- React
- TypeScript
- Tailwind CSS

## Notes

This app is intentionally self-contained and does not depend on a backend. It is designed to be a strong frontend foundation for a future AI-powered planning workflow.
